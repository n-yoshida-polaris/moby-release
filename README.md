# Moby

**Moby（モービー ＝ **M**y vide**O** li**B**rar**Y**）** は、PC内の動画・画像をまとめて管理し、最大4本の動画を同時に再生できる Windows 用デスクトップアプリです。

## 主な機能

- 📚 **ライブラリ管理**：フォルダ内の動画・画像を自動で取り込み、サムネイル付きで一覧表示
- 🖥️ **4画面マルチビュー**：最大4本の動画を並べて同時再生。スロットの入れ替え・並べ替えも可能
- ⭐ **整理**：お気に入り、星評価、タグ付け、コレクション（プレイリスト）
- 🔍 **検索・並べ替え**：ファイル名・タグでの検索、各種ソート
- 🗂️ **画像フォルダ表示**：画像をフォルダ階層のまま閲覧
- 🎞️ **対応形式**：動画 `.mp4` `.mkv` `.webm` `.mov` `.flv` ／ 画像 `.jpg` `.png` `.gif` `.webp` `.bmp` `.svg` `.avif`
- 🔒 **完全ローカル動作**：動画や情報を外部に送信しません

## ダウンロード

[**Releases**](https://github.com/n-yoshida-polaris/moby-release/releases/latest) から最新の `Moby-x.y.z-portable.exe` をダウンロードしてください。

- 動作環境：Windows 10 / 11（64bit）
- インストール不要（ポータブル版）。exe を好きなフォルダに置いてダブルクリックするだけで起動します

### 「WindowsによってPCが保護されました」と表示された場合

Moby は現在コード署名を行っていないため、初回起動時に Microsoft Defender SmartScreen の警告が出ることがあります。
**「詳細情報」→「実行」** をクリックすると起動できます。

## 使い方

1. 初回起動すると、exe と同じフォルダに `videos` フォルダが作られます
2. `videos` フォルダに動画をコピーし、画面右上の **再読み込み** ボタンを押すと一覧に表示されます（サブフォルダもOK）
3. 既存の動画フォルダ・画像フォルダを直接登録したい場合は、アプリの **設定** 画面でフォルダを指定してください（カンマ区切りで複数指定可。反映には再起動が必要です）

### データの保存場所

exe と同じフォルダに以下が作られます。別のPCへ移すときは exe と一緒にまとめて移動してください。

| ファイル / フォルダ | 内容 |
|---|---|
| `library.db` | お気に入り・評価・タグ・コレクションなどの情報 |
| `thumbnails/` | サムネイル画像 |
| `videos/` | 既定の動画フォルダ |
| `.env` | 設定内容 |

このほか、画面の表示設定（ループ再生・フォルダのサムネイル指定など）とキャッシュが `%APPDATA%\moby` に保存されます。

### アンインストール

インストールは行っていないため、以下を削除するだけで完了です。

1. `Moby-x.y.z-portable.exe` と、上の表のファイル・フォルダ（`videos/` 内の動画ファイルは必要に応じて退避してください）
2. `%APPDATA%\moby` フォルダ（エクスプローラーのアドレス欄に `%APPDATA%` と入力すると開けます）
